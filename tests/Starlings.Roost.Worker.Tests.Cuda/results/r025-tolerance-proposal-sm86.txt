Notes for the maintainer:
  - Hidden-state differences are whole bf16 steps at the layer's scale (for example 0.03125 where the largest value is 2 to 4), so the relative form
    max|d| / max|ref| is the natural one; an absolute bound would need a per-layer table (the report has one).
  - Logits max|d| reaches 0.23 while the smallest top-2 margin seen was 0.235 (GPU) / 0.279 (CPU), so a greedy flip is possible in principle at
    this noise level even though none occurred. A greedy gate therefore needs the margin rule above, or the fixtures must be chosen with margins
    well clear of it; an unconditional "greedy tokens equal" gate would be flaky on near-ties.
  - Per op class (worst relative max|d| over all traced steps and layers, from the report): Gemm 0.045, RmsNorm 0.030, SiluAndMul 0.030,
    PagedAttention 0.026, GatedRmsNorm 0.025, GatedDeltaRuleGates.g 0.018, GatedDeltaRule.out 0.013, SigmoidMul 0.013, CausalConv1d.out 0.012,
    QkNorm and Rope 0.012, LmHead.logits 0.010. Op-level bounds should come from R-019's conformance runs, which test each op on its own
    inputs; these numbers include the error carried in from earlier layers.
  - Determinism: a second GPU process produced a bit-identical dump (tokens, logits and every recorded op output), so the differences above
    are not run-to-run noise on this device.
